# Changelog

## 0.1.0 - 2026-11-18

- Initial release.
- Dependency-free Node.js (`benchmark.mjs`) and standard-library Python (`benchmark.py`) CLI tools measuring SSE streaming Time-To-First-Token (`TTFT`), end-to-end latency (`p50`/`p95`), token counts, and `hostlinku.cost` USD usage.
- Supports JSON (`--json`) and human-readable table output across custom `--model`, `--runs`, `--max-tokens`, and `--mode` (`stream` | `chat`).
- Multilingual README (`en`, `id`, `ja`, `zh-CN`) with date-stamped reference run results from 2026-11-18 and CI syntax workflow.
